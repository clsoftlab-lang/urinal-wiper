        🎓 아이디어 출처 / Idea origin
        
        
        이 프로젝트는 이일국 박사(Dr. Lee Il-guk)의 용인대학교(Yongin University) 창업 수업에서 나온 한 학생의 돋보이는 아이디어에서 영감을 받았습니다. 원 아이디어에 감사드리며, 어떤 문장·자료도 복제하지 않은 클린룸(clean-room) 방식으로 개념만 독립 재구성했습니다. 개인정보·상표는 포함하지 않습니다.
        
        
        This project was inspired by a standout student idea from Dr. Lee Il-guk's entrepreneurship class at Yongin University. Built clean-room with gratitude to the original idea — no copied sentences, no PII, no trademarks.
        
      
        
      
        
        
        개념 경계 · DEMO-MODE
        
        
        이 저장소는 개념 시뮬레이터 + 설계 문서입니다. 실제 제조·판매 제품이 아니며, 수치(위생 점수·소비량·시간)와 BOM 가격은 추정·참고용이며 검증되지 않았습니다. AI 기능은 기본적으로 Mock(데모)으로 동작합니다.
